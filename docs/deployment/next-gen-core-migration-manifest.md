# Next-Gen Core migration manifest

The R1 embedded-Postgres suite applies **all** repository migrations from zero, not only this table, using real `pgvector`. It also applies the complete pre-M2 chain, inserts a realistic legacy workspace, then applies rows 1-9. The deployment target remains unverified until the runbook is executed against the linked project.
