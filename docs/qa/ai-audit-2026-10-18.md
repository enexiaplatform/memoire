# AI functional audit — 2026-10-18

## Scope and evidence boundary

Audit the existing chat loop: grounded readings, conversation continuity, draft conversion, cancel/confirm, duplicate prevention, record identity, error handling and source scope. Reuse canonical stores and engines; no schema or dependency changes. Business writes are fictional/in-memory only. Production smoke is read-only. This is a functional audit, not an exhaustive security assessment or a claim that all model answers are correct.

## Confirmed defects and corrections

| Defect | Before-fix reproduction | Correction |
| --- | --- | --- |
| Cancelled/processed draft could be revived | Reference lookup skipped the newer cancellation/execution message and recovered an older assistant proposal. A regression failed before the fix. | The latest assistant message must be the valid draft. Cancellation, execution and other terminal feedback stop reference reuse; a fresh draft or explicit new task is required. |
| Long visible draft was cut in history | Answer and editable draft were displayed in full but their combined transcript was sliced at 6,000 characters. Conversion could use incomplete task details. A regression failed before the fix. | One shared transcript builder is used by the panel and conversion guard. If the complete visible proposal exceeds history capacity, conversion requests smaller batches before any provider call or write. |
| Vietnamese new-work commands reused a previous draft | The add verb “thêm” normalized to “them” and matched an English reference-pronoun check. A named request for another customer returned the previous draft context. | Separate English pronouns from Vietnamese add verbs; require actual reference phrases such as “các việc trên”. Explicit named new work remains a fresh lookup, including after cancellation. |
| Exact task already in next week's manual Plan was re-proposed | An old opportunity next-action date still produced a candidate despite an open, explicitly linked Plan item with the same task next week. A regression failed before the fix. | Exclude exact normalized task + opportunity-ID matches already planned in the target week. Different work, different IDs, dismissed/deleted and out-of-week records remain separate. No fuzzy/name-based merging. |

The initial pre-fix audit regression run had three failures and one passing boundary case. A later separate language regression also failed before its fix. The corrected focused AI run passes 78 tests, including the existing scope/privacy, canonical analytics, strict action fields, stale/partial writes, provider budget and reference-identity regressions.
